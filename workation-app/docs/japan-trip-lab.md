# 일본 여행 실증용 Global Lab

접속: `/dashboard/global-lab` 또는 마이페이지의 ‘일본 여행 기록’ 링크.

## 범위

- 2026-09-12~09-16, 예산 420,000원을 초기값으로 제공. 날짜·예산·질문 수정 가능.
- 목표·완료 기준·결과물, 업무/휴식 시작·종료와 재개, 일본 시간 기준 종료 시각 수정.
- 피로도 전후·전날 휴식 후 회복감을 직접 기록.
- 영수증 사진, 엔화, 건별 환율, 선택적인 실제 원화 결제액. 지출 수정·삭제.
- 장소별 벤치마킹 메모와 사진. 일자별 활동·지출·사진을 모은 인쇄/PDF 보고서.
- IndexedDB 기기 저장. 사진 포함 JSON 백업·검증 후 복원.
- 프로덕션에서 해당 경로만 제어하는 서비스 워커. 온라인 최초 준비 완료 후 오프라인 재열기 지원.

## 여행 전 / 매일

1. 사용할 휴대전화의 일반 브라우저에서 배포 주소를 열고 홈 화면에 추가하거나 북마크.
2. 여행 설정에서 1엔당 원화 환율을 직접 입력. 초기값 0은 미설정이며 지출 저장 시 양수 입력 필요.
3. ‘오프라인 화면 준비 완료’ 표시 후 비행기 모드에서 새로고침과 기록 저장을 시험.
4. 매일 기록 저장 후 ‘사진 포함 백업’을 다운로드하여 별도 보관. 다른 기기에서는 백업을 복원.
5. 마지막 날 진행 중인 타이머를 종료하고 결과 보고서에서 인쇄 → PDF로 저장.

## 저장과 격리

국내 DB·예약·보조금·로그인·API는 변경하지 않음. 기존 코드 변경은 마이페이지 링크 한 개뿐임.
전용 IndexedDB `workation-japan-lab-v1`, 전용 캐시 `workation-trip-offline-v1` 사용.
동일 브라우저 프로필에서 한 여행을 사용하는 개인 실증 도구임. 계정별 저장·서버 동기화·팀 공동 편집 없음.
동시에 여러 탭에서 편집하지 말 것. 브라우저 데이터 삭제·저장소 정리 시 로컬 기록이 제거될 수 있어 백업 필수.
사진은 JPG/PNG/WebP, 1장 최대 8MB. HEIC·PDF 첨부는 지원하지 않음. 사진 포함 백업 복원은 100MB 이하.
기기 저장 실패 시 완료로 표시하지 않으며, 저장 전 입력은 페이지 전환 시 확인함.

## 자동화 범위

AI 리포트, OCR, 노션 전송, 외부 알림 차단, 회사 승인·전자서명·법정 수당 판정은 구현하지 않음.
현장 노트를 그대로 취합하므로 별도 API 키·과금·DB 마이그레이션 없이 실행 가능.
원화 환산은 입력 환율 기준 예상액. 실제 결제액이 있으면 그 금액을 합계에 사용.
동네 가게 분류는 사용자 확인 결과이며 지역 경제 기여나 지원금 적격성을 자동 판정하지 않음.

## 확인 방법

`npm ci`, `node --test tests/global-lab.test.cjs`, `npm run build`, `npm run start`.
모바일에서 목표 입력→업무 시작→휴식→종료→저장, 사진 지출→수정, 새로고침, 백업 복원, 오프라인 재열기, PDF 출력을 확인.
배포는 기존 운영 절차에 따라 별도 진행. 개발 브랜치를 운영 브랜치에 반영하기 전 검토 필요.
