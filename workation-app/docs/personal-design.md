# 개인 업무 공간 설계 근거 · 2026-10-07

## 근거와 적용
사용성 가이드와 제품 패턴을 근거로 설계했으며, 우리 고객 대상으로 효과를 정량 검증한 것은 아니다. 개선율이나 시간 절감 수치를 임의로 주장하지 않는다.

| 근거 | 적용 |
|---|---|
| NN/g의 Recognition Rather than Recall: 기억보다 화면에서 상태·선택지를 알아보게 한다. | 단계 번호, 선택한 업무, 누적 시간, 연결 상태를 화면에 표시한다. |
| NN/g의 Progressive Disclosure: 기본 작업과 보조 기능을 분리한다. | 도구 활동, 백업·복원과 저장 안내는 펼쳐보기로 제공한다. |
| Toggl Timer Mode: 타이머의 명확한 시작·종료 조작. | 작업 화면에서 한 업무를 선택하고 큰 시작·일시정지 버튼을 사용한다. |
| Linear My Issues: 자신에게 중요한 업무에 집중하는 뷰. | 전체 업무를 요약 목록으로 보여주고 선택한 업무만 상세 편집한다. |

- https://www.nngroup.com/articles/progressive-disclosure/

## 브랜드와 강조
사용자 요청에 따라 왼쪽 컬러 테두리·왼쪽 inset 그림자를 제거했다. 로고는 헤더, 개인 문서, 하단에 사용한다. 선택한 업무는 카드 전체 배경과 번호 배지, 현재 단계는 채워진 브랜드 컬러, 시간 측정은 진한 배경과 큰 숫자로 강조한다. 화면 내용을 가리는 장식과 반복 타이머를 줄인다.

## 검증과 남은 작업
TypeScript·기능 테스트 및 PC 화면을 확인한다. 개발 전용 `/personal-preview`에서 실제 기록을 변경하지 않고 흐름을 점검할 수 있다. 고객 사용성 검증은 첫 타이머 시작까지 걸린 시간, 잘못된 단계 이동 횟수, 증빙 포함 문서 완성 여부를 관찰하는 방식으로 별도 진행해야 한다.

## 실제 화면 검수 결과
PC와 390px 모바일 화면 확인. 검수용 예시에서 20초 타이머 누적·정지, PNG 원본 저장·설명 입력·개인 문서의 사진 반영을 확인했다. 기존 개인 기록은 변경하지 않았다. 동영상 파일 재생과 인쇄/PDF의 최종 출력 검수는 아직 남아 있다. 최종 화면 캡처는 현재 대화 작업 폴더 outputs에 저장했다.

도구 선택 버튼과 도구별 연결 제목에 GitHub·Notion·Slack SVG 로고를 추가했다. Slack은 공식 색상 형태를 사용하고 텍스트 이름·연결 상태를 함께 표시한다. 파일을 public/tool-logos에 저장해 실행 시 외부 로고 서버에 의존하지 않는다. 브라우저에서 표시를 확인했다.
