# 개인용 업무 도구 · 2026-10-07

경로: `/personal`. 홈, 로그인 화면과 공통 메뉴에서 진입 가능. 가입·회사 계약·승인 없이 사용한다.

목표 설정 → 진행률·시간·메모 기록 → 결과 설명·증빙 링크 → 문서 미리 보기 → 인쇄/PDF 저장.

## 구현 범위
- 업무 최대 20개, 이름·기간·장소, 목표·완료 기준·기한·예상 시간.
- 진행 상태·실제 시간·메모, 업무별 결과 설명과 http/https 증빙 링크.
- 현재 브라우저 localStorage 자동 저장, JSON 백업 및 복원.
- 개인 문서에는 회사 제출·관리자 검토 상태를 표시하지 않는다. 기록은 본인 작성 자료다.
- 회사용 API 및 DB 권한은 변경하지 않았다. 개인 기록을 서버로 전송하지 않는다.

## 사용상 제한 / 다음 개발
1. 개인 계정과 전용 DB 저장·소유자 권한 정책: 여러 기기에서 이어서 사용하고 분실 방지.
2. 날짜별 업무 기록: 현재 메모는 업무당 누적 메모로 수정된다.
3. 파일 증빙 업로드와 제목·설명: 현재는 외부 링크만 지원한다.
4. 공유용 읽기 전용 링크와 사용 후기 수집: 현재 PDF를 사용자가 직접 전달한다.

브라우저 데이터 삭제·시크릿 창 종료 시 기록을 잃을 수 있다. 백업 파일도 업무 내용을 포함하므로 사용자 본인이 관리한다. 잘못된 저장 데이터는 자동 덮어쓰기를 중단하며 유효한 백업을 복원하면 재개한다.

검증: TypeScript 검사, 개인 백업/문서 검증 테스트, 기존 회사 업무 API 테스트. 실제 개인 계정 동기화와 파일 업로드는 미구현.

## UI 개선 · 2026-10-07
현재 단계·다음 행동을 강조하고, 기본 정보와 업무별 입력 카드를 분리했다. 저장 안내는 펼쳐보기로 제공하며 모바일에서는 하단 주요 버튼을 넓게 표시한다. TypeScript 검사를 진행했으며 실제 브라우저 시각 검수는 로컬 실행 환경 문제로 미완료다.

## 時間測定 / 업무 시간 측정 · 2026-10-07
업무별 시작·일시정지, 초 단위 누적 시간과 작업 횟수를 추가했다. 동시에 한 업무만 측정한다. 화면이 숨겨지면 자동 일시정지하며 새로고침 후에는 정지 상태로 복원한다. 절전·중단으로 5초 넘는 간격은 계산하지 않는다. 측정 시간은 문서에 분 단위로 반영하며 직접 입력 기록과 구분한다. 타이머 값도 브라우저에 저장·백업된다. 외부 도구 활동 수집은 사용 도구 확인 후 연결 예정이며 아직 미구현이다. 타이머는 실제 업무 활동·성과 인증이 아니다.

## 단계별 화면과 시각 증빙 · 2026-10-07
목표 설정에는 목표 입력만, 업무 기록에는 시간 측정·진행 상태·메모와 총 시간 현황, 결과 증빙에는 결과 설명·링크·사진/영상 첨부, 문서에는 증빙 미리보기를 표시한다. 단계 이동 시 타이머를 정지한다. 파일은 브라우저 IndexedDB에만 저장하며 서버 업로드는 아직 아니다. JPG/PNG/WebP/MP4/WebM, 파일당 20MB, 목표당 6개. 전체 백업은 원본 포함 60MB까지, 복원 시 새 파일 ID를 사용한다. 영상은 화면에서 재생하고 PDF에는 첫 프레임 대표 이미지와 설명을 표시한다. 브라우저 데이터 삭제 전에 원본 포함 백업이 필요하다. 실제 영상 재생·PDF 출력의 시각 검수는 미완료다.

## 최신 진행 상태 · 2026-10-07
Notion·Slack 개인용 흐름은 기존 서버 인증 정보와 기존 callback URL을 재사용하도록 구현했다. 개인 연결 요청은 별도 state를 검증해 기존 callback에서 개인 처리로 분기하며 토큰은 암호화 HttpOnly 쿠키로 보관한다. 서버 secret 기반 암호화 키 파생을 지원해 별도 키 설정 없이 기존 서버 환경을 재사용할 수 있다. GitHub 인증 설정은 여전히 미등록이다. 현재 코드는 로컬 변경 상태이며 Git push/배포하지 않았다. 실제 서비스 계정 로그인 검증은 배포 후 필요하다. 디자인은 사용자 요청대로 좌측 색 테두리 강조를 제거하고 실제 로고를 헤더·문서·하단에 배치했다.

## 입력 부담 개선 · 2026-10-07
개인용 수동 달성률 입력을 제거하고 문서에서도 해당 값을 표시하지 않는다. 계획 이름·작성자·기간/기한·목표/기준·결과의 5개 항목으로 문서 준비 상태를 자동 계산한다. 업무 달성률/지원금 지급률과 구분한다. 도구 활동으로 업무 초안을 만드는 버튼을 추가했다. 외부 도구 실제 데이터 조회는 배포 후 검증 필요. 지자체 지원금은 공고 기반 별도 자격/금액/제출조건 모델로 설계 예정이며 아직 계산 기능 미구현.
